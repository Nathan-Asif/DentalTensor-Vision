## Reporting a Vulnerability

We take the security of DentalTensor Vision seriously. If you believe you have discovered a security vulnerability or sensitive data exposure, please do **not** open a public issue.

Instead, please report it privately:
- Contact: Nathan Asif
- Via: Private GitHub Security Advisory or direct repository contact

Please include:
- A description of the vulnerability.
- Steps or a minimal proof of concept to reproduce the issue.
- Potential impact on users or deployments.

We will acknowledge receipt within 48 hours and work diligently to release a patch promptly.
